## 1. 总命题

**冻结通用生成器 + LoRA 风格** 不是一种工程妥协，而是论文"可回退效应 + 响应式协效应"
框架的一个特例，且恰好落在该框架中最强的一类效应上。

- 冻结先验 \(W_0\)（`FSQCanonicalTransformerGenerator`，`causal_transformer_generator.py:626`）
  是**共享上下文**：一切风格效应的读取对象，自身不接受任何风格写入。
- 一个 LoRA 风格是一个**组件**（论文 定义 43 的三元组 \((d, p, e)\)）：
  声明所需协效应 \(d\)、权重坐标 provision \(p\)、以及一个带见证的效应函数 \(e\)。
- LoRA 的权重增量 \(\Delta W = BA\) 使效应函数成为**归纳对**（induced pair）：
  前向 \(W \mapsto W + \Delta W\)，逆 \(W \mapsto W - \Delta W\)，对每个状态恒有
  \(g \circ f = \mathrm{id}\)。论文 定义 8 明确指出归纳对"在每个状态都产出一个逆"，
  属于见证效应 \(\mathfrak{E}^*_\Gamma\)——该理论中可回退性最强、无需附加假设的类别。

论文 §1.2.3 对"粗粒度变通方案"（重配置只能重启、丢弃运行时状态）的批判，逐字对应
"每风格全量微调 = 每风格一个新模型"。冻结先验 + LoRA 把风格从**权重的一部分**变成
**运行时可装卸的组件**，这是本架构的理论立场，而非仅仅是参数经济性。

## 2. 形式化基础：上下文与两本账

生成过程的上下文定义为

\[
\Gamma_{\mathrm{ctx}} \;=\; (W,\; C,\; \Sigma),
\]

- \(W\)：有效权重，\(W = W_0 + \sum_{i \in S} \alpha_i B_i A_i\)，\(S\) 为活跃风格集；
- \(C\)：自回归运行态（`FSQGeneratorCache` 的逐层 KV 滑动窗口）；
- \(\Sigma\)：依赖表（哪个 fiber 提供哪个风格键）。

此外引入**输出带** \(\tau\)：已发射的 FSQ token / 运动帧序列，append-only。

**账本分离（本方案对论文统一上下文 \(\Gamma_\infty\) 的一处修正）。** 论文把效应统一记在
一个上下文上；生成场景必须把账本劈成两本：

1. **上下文效应**（作用于 \(W, C, \Sigma\)）：可回退，撤回义务只绑在这本账上；
2. **带效应**（作用于 \(\tau\)）：风格在 \(t\) 之前塑造的动作是**产品而非污染**，
   永不回退。

这与论文 §3.3.2 的观察等价立场一致（"free 释放内存但不复原堆布局"）：我们复原的是
**机器**（权重、缓存、依赖表），不是已产出的**动作**。论文的 malloc 例子在那里是需要
容忍的理想化缺口，在生成场景里则是定义使然。

## 3. 权重空间：精确可回退与交换性

**命题 1（权重空间精确可回退与历史无关）。** 对任意激活、撤回、强度调节序列：

1. 全部撤回后 \(W = W_0\)，逐位成立；
2. \(W(S, \alpha) = W_0 + \sum_{i \in S} \alpha_i \Delta W_i\) 只依赖当前活跃集与强度，
   不依赖到达它的历史；
3. 任意两个 fiber 的权重变换交换：\(f_i \circ f_j = f_j \circ f_i\)。

证明：向量加法构成交换群，逐条直接。\(\square\)

这使论文中最难的结构性质按构造成立而非按训练成立：

- **定理 7 / 定理 16**（累积器恢复、LIFO 回退）的权重分量：精确，且比 LIFO 更强
  （任意顺序皆可）；
- **定义 19**（效应独立性）的两个子句：权重变换交换（子句 1）与互不破坏对方之逆
  （子句 2）皆精确成立——\(\Delta W_i\) 的存在不改变 \(-\Delta W_j\) 的恢复效果；
- **强度渐变 = 效应迭代**（§4.3.2）：\(W + \alpha \cdot BA\)，每一步 \(\alpha \mapsto
  \alpha + \delta\) 携带逆 \(\alpha \mapsto \alpha - \delta\)。风格淡入淡出因此是
  一列**全程可逆的微效应**，滑杆任意时刻可精确反向。LoRA 标准的 \(B\) 零初始化进一步
  保证激活瞬变 \(\alpha = 0\) 对权重是无操作——"加载即执行效应"的连续化。

## 4. 运行时状态：缓存卫生与有界污染视界

权重空间的可回退性**不**自动传递到生成层，因为存在第二本共享状态账：KV 缓存。

**命题 2（缓存污染引理）。** 本生成器为 pre-norm 残差 Transformer：第 \(l\) 层缓存
\(K_l = W_k^l h_l\)、\(V_l = W_v^l h_l\)，其中 \(h_l\) 由残差流
\(x_l = \mathrm{emb} + \sum_{j < l} u_j\) 决定。因此**任何**触及 \(j < l\) 层模块或
embedding 的 \(\Delta W\) 都会使 \(K_l, V_l\) 依赖活跃风格集。推论：仅当 LoRA 局限在
输出头（晚于一切缓存写）时缓存才风格不变；任何体级 LoRA 必然污染 \(C\)。
\(\square\)

注意：这一引理对现有 `DynamicStyleFiLM` 同样成立（FiLM 在 attention 输入端调制，
先于 QKV 投影，`causal_transformer_generator.py:297`），LoRA 并不更差——差别在于
LoRA 额外拥有命题 1 的权重代数，而 FiLM 的逐帧动态调制无法进行任何结构性叠加。

**命题 3（有界污染视界 / 时空可组合性的生成语义）。** 设风格切换发生在 \(t_0\)，
滑动窗口长度 \(H = \mathtt{context\_frames} = 64\)。

- **弱保证（免冲刷）**：\(t \ge t_0 + H\) 时，\(C\) 中已不含前任风格集下计算的 K/V
  （滑窗逐出）。给定已发射带 \(\tau\)，生成器内部状态与新活跃集"静态组装并发射同一
  \(\tau\)"的状态在论文 §3.3.2 的观察等价意义下相等。切换的完整生效存在至多 \(H\) 帧
  的过渡视界——这正好为风格切换提供一段自然的混合过渡，而非缺陷。
- **强保证（付费精确）**：在 \(t_0\) 冲刷缓存，用当前活跃集重算最近 \(\le H\) 帧的
  K/V（re-prefill），则自 \(t_0\) 起续写精确等于静态组装的续写（贪心解码下逐 token
  相等）。精确性的价格是 \(H\) 次 decode 步，本仓库 \(H = 64\)，代价可忽略。
- 带上 \([t_0, t_0+H)\) 内发射的帧是带效应，永不回退。\(\square\)

**冻结前缀作为协效应。** 采用强保证后，条件生成可恢复使用冻结前缀：前缀 K/V 一律以
\(W_0\) 计算，声明为编排者（root fiber）的 provision，风格 fiber 只读。这解除了现有
条件生成器对前缀的禁用（"conditional caches must not contain prefix tokens"），并
带来跨风格一致性：所有风格从**同一个** canonical 种子状态续写，风格切换不改变种子
身份。形式上，前缀是被提升为协效应的共享状态——"风格可读先验、而不成为先验自回归
状态的一部分"这一既有设计注释的字面实现。

## 5. 编辑史无关性（会合性）与编辑能力语义

**命题 4（编辑史无关性）。** 权重层由命题 1(3) 精确成立：任意中途编辑序列的终态等于
以最终风格集静态加载的终态（定理 73 会合性的结构分量）。生成层在命题 3 强保证下
自切换点精确成立；弱保证下自切换点 + \(H\) 成立。\(\square\)

由此给出"撤销一次风格编辑"的三层语义，实现与验收以此为准：

1. **机器层**：\((W, C)\) 精确复原（命题 1 + 命题 3）；
2. **内容层**：tape 不复原，已生成动作保留（账本分离）；
3. **语义层**："风格回到从前" = 机器层复原 + 续写精确性，用户感知为"那一段风格
   从未发生过，但动作还在"。

编辑能力因此不是功能清单，而是一组**可组合的过渡原语**，各自携带精确的保证级别
（见 §8）。

## 6. 空间维：provision 不相交与语义独立性

**provision 的 LoRA 字面化。** 论文 定义 43 要求"provision 之外的键一概不写"。对
LoRA 这不是抽象义务而是可机械执行的白名单：`target_modules` 枚举该 fiber 允许写入的
权重坐标，loader 在装配时校验。每个风格键（如 `style/gait`）同一时刻至多一个活跃
提供者；第二个同键风格走 reload 语义（先精确撤旧、再激活新），而非未定义叠加。

**命题 5（诚实条款：语义独立性是经验性质）。** 网络映射 \(\mathcal{G}(W, \cdot)\)
非线性，故命题 1(3) 的权重交换**不**蕴含动作层非干扰。定义非干扰为

\[
\mathcal{G}(W_0 + \Delta W_i + \Delta W_j;\, \cdot) \;\approx\;
\oplus\bigl(\mathcal{G}(W_0 + \Delta W_i;\, \cdot),\;
\mathcal{G}(W_0 + \Delta W_j;\, \cdot)\bigr),
\]

其中 \(\oplus\) 是声明的动作级组合算子。这是**训练出来的性质**，结构只能提供使它
可测量的框架。训练侧杠杆：

- **模块级 provision 不相交**：各风格轴分配不相交的 `target_modules`，\(\Delta W\)
  在权重空间无共享坐标；
- **子空间级不相交**：同模块内以正则 \(\lVert A_i A_j^{\top} \rVert^2\) 约束不同
  fiber 的更新子空间正交；
- **强度感知训练**：训练时采样 \(\alpha\)，使 \(\alpha\)-路径在流形上，避免推理期
  强度值落在分布外。

论文的贡献在此是把"多风格叠加好不好看"从玄学变成一个有定义、有测试的命题。

## 7. 组件契约：LoRA 风格包

风格包为声明式条目（对齐论文 §5.2.1 的 entry 与本仓库 `data/configs/` 惯例）：

```yaml
id: style/injured_limp            # 调和键（§5.2.1），查看器热替换按 id 对账
base_sha: "<W0 checkpoint sha256>" # 依赖版本（§6.6）；loader 拒载错配 base 的包
requires:                          # 协效应 d（定义 25/26）
  - ctx/trajectory
  - ctx/canonical_prefix
provides: [style/gait]             # provision p（定义 43），活跃集内不得相交
target_modules:                    # p 的机械执行形式：允许写入的权重坐标白名单
  - blocks.{4,5}.ffn
  - head
rank: 8                            # 沙箱广度（§6.3）：可达集为 W0 附近 r 维代数簇
alpha: 16
strength: { init: 0.0, ramp_frames: 12 }   # 效应迭代（§4.3.2），每步可逆
on_conflict: replace               # 同键第二提供者 → reload（精确撤旧再激活）
on_missing: deactivate             # 通知 = deactivating → 按 ramp 淡出
on_error: retire                   # L-Raise → 恢复 → Inactive，兄弟不受影响
```

字段—论文对照：`id` ↔ 调和键；`base_sha` ↔ §6.6 依赖类型与版本；`requires` ↔ 协效应
规范；`provides`+`target_modules` ↔ provision（本方案把论文的"键"具体化为两类坐标：
\(\Sigma\) 中的运行时信号键与 \(W\) 中的权重坐标键——论文 §3.3.1 明确 \(\Sigma\) 的
值类型不受限，二者可共存于同一依赖表）；`rank` ↔ §6.3 访问控制的沙箱宽度；
`strength.ramp_frames` ↔ 过渡中的迭代；三个 `on_*` 策略 ↔ 通知分类与失败语义。

**base_sha 契约**沿用 `generate.py` 中 tokenizer 检查点 SHA256 绑定
（`validate_generator_contract`）的既有机制：针对 \(W_0^{v2}\) 拟合的 LoRA 对
\(W_0^{v3}\) 是未定义行为，必须在装载时拒绝，而非运行时静默劣化。

## 8. 生命周期语义（对齐论文 §4.3）

- **激活**（L-Begin → L-Iter）：\(\alpha\) 以 `ramp_frames` 步 \(0 \to\) target，
  每步携带逆。激活起点 \(\alpha = 0\)，机器无瞬变。
- **同键切换**（L-Divert 惯性语义）：新 fiber 先着陆（激活完成），旧 fiber 再失活
  （L-Unload）；切换在帧边界生效，绝不打断一次 decode；是否冲刷缓存按 §9 的保证
  级别选择。弱保证下，\(H\) 帧过渡视界即天然的混合过渡。
- **依赖撤回**（§4.3.1 Withdrawal）：若 fiber \(\ell_2\) requires \(\ell_1\) 提供的
  键，\(\ell_1\) 的卸载必须排在 \(\ell_2\) 淡出之后（论文 `relied` 谓词：先查谁
  解析到了我）。编排者在撤回前执行该检测。
- **失败**（§4.3.4 L-Raise）：活跃中产出 NaN / 非法 FSQ level ⇒ 精确减去该 fiber 的
  \(\Delta W\)（命题 1 保证恢复无损）、按需冲刷、错误记在该 fiber、兄弟继续、且不对
  同一状态自动重试（错误结局不重入生命周期）。LoRA 使失败恢复从"尽力而为"变成
  "结构性无损"。
- **通知**（定义 26）：任何上下文变换（中途改轨迹、增删风格、撤键）按各 fiber 的
  `requires` 分类为 activating / deactivating / neutral；deactivating 触发按 ramp
  淡出。例：用户中途把轨迹加速到超出"受伤跛行"所声明的速度带，该风格在
  `ramp_frames` 内优雅退场，而不是硬产出与轨迹冲突的动作。

## 10. 可测试不变量（对接 `tests/`）

- **T1 权重恒等式**：任意装载/卸载/强度序列结束后 \(W\) 与 \(W_0\) 逐位相等。
  纯单元级，不涉生成。
- **T2 续写精确性（强保证）**：贪心解码，风格 \(S\) 激活 60 帧 → 切换时冲刷 →
  \([60, 120)\) 与"从头装 \(S'\)、同一 canonical 前缀"逐 token 相等。
- **T3 视界精确性（弱保证）**：不冲刷；断言 \(t_0 + 64\) 后缓存与"用新风格对同一条
  token 带 re-prefill"的缓存数值一致（缓存 provenance 检查）。
- **T4 会合性**：同一 seed 下，A→B 中途切换（冲刷）的续写 == 静态装 B 的续写；
  A、B 模块不相交时 A→B == B→A。
- **T5 强度可逆性**：\(\alpha: 0 \to 1 \to 0\) 后权重逐位复原（T1 的参数化版本）。
- **T6 失败隔离**：注入产 NaN 的风格 ⇒ 该 fiber 退役、\(W\) 精确复原、其余风格与
  canonical 生成不受影响、错误记录在该 fiber。
- **T7 base_sha 契约**：错配 base 的风格包拒载（仿 `validate_generator_contract`）。
- **T8 通知语义**：中途把轨迹改出 `requires` 谓词 ⇒ 该风格在 `ramp_frames` 内淡出
  至 0，全程无 NaN、无非法 level。
- **T9（既有）**：`tests/test_canonical_generator.py` 断言 canonical 生成器无风格
  参数——本理论下升级为契约测试："先验不是任何 fiber 效应的写入对象"。

## 11. 与 DynamicStyleFiLM 的关系及混合方案

公平比较：FiLM 在"模块卸载"意义下同样权重可逆（不施加调制即可），真实差异在：

1. **图随风格数增长**：每风格需要一套 FiLM 模块（图变化）；LoRA 在固定图上以加法
   组合，部署物只有一份 \(W_0\) + 若干低秩增量。
2. **组合代数**：多 FiLM 在同一 block 上以非线性方式叠加（tanh 门控），无交换性
   可言；LoRA 增量精确相加（命题 1）。
3. **表达力**：FiLM 的逐帧动态调制（条件于因果状态）严格强于静态 LoRA——这是
   LoRA 用表达力换来的可组合性与沙箱性，必须诚实声明。

**混合方案**（演进 `STYLE_CONDITIONING`：`causal_dynamic_block_film_v1` →
`frozen_prior_lora_v1[+gate]`）：LoRA 承载**静态风格先验**（可逆、可组合、低秩
沙箱），一个轻量动态门恢复**逐帧变化**；门的输入条件于风格不变的信号（canonical
分支的每帧状态——这正是保留 canonical generator 作为只读先验分支的第二个理由），
门本身纳入同一效应协议（apply/revert）。动态门若写缓存路径，则同样受命题 2/3
管辖；若只作用于缓存写之后（输出端），则免冲刷。

## 12. 沙箱与多路复用

- **rank 即权限广度**（§6.3）：单 fiber 的可达集
  \(\{W_0 + BA : B \in \mathbb{R}^{d \times r}, A \in \mathbb{R}^{r \times k}\}\)
  是 \(W_0\) 附近的 \(r\) 维代数簇——fiber 对先验的最大改写幅度被结构封顶。
  `target_modules` 给出权限位置，`base_sha` 给出目标机器。三者合起来就是风格
  组件的"权限证书"。
- **多路复用**（§6.2 + 定义 28 isolation realms）：一份 \(W_0\) 常驻显存，多个
  并行会话各自构成 isolation realm，在各自 realm 内解析风格键——同一先验同时服务
  多套风格组合的内存经济性，是本架构的直接工程红利。

## 13. 边界与诚实条款

1. 本理论保证**结构**（哪台机器、哪个状态、哪段历史、谁能写哪），不保证**语义**
   （风格像不像、组合是否协调、动作是否真实）。语义由表示层与训练目标负责
   （`docs/latent_residual_part_fsq_v2_spec.md`、§6 的训练杠杆）。
2. 命题 5：语义独立性是经验性质；本框架的贡献是给它定义、杠杆和测试，而非保证。
3. 低秩是双刃剑：它是沙箱（容量封顶）也是天花板（风格容量上界）。rank 的选择是
   权限与表达力的显式权衡，应按风格轴分级设定，而非全局统一。
4. LoRA 是静态权重增量，逐帧动态性弱于 FiLM；需要逐帧动态时走 §11 混合方案，
   并接受相应的缓存卫生条款。
5. 弱保证下的 \(H\) 帧过渡视界是架构常量（`context_frames`），不是可调的美学参数；
   需要更短的过渡视界时，正确手段是付费冲刷（强保证），而非压缩窗口。
